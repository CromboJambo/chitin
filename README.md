# chitin

Minimal Wayland compositor and desktop shell built from crates. GPU-accelerated via wgpu, container-friendly, agent-controllable.

The structural material of a crab's shell — the hard layer everything else renders against.

## Status

Pre-alpha. Spec-first development; no implementation yet. See [specs/SPEC.md](specs/SPEC.md).
